# Privacy

OmniGPU is designed for local operation. It has no OmniGPU account, advertising SDK, usage analytics service or automatic crash upload.

## Data stored locally

- application preferences, game presets and tuning profiles;
- benchmark history and optional CSV telemetry logs;
- driver/profile backup metadata and recovery records;
- screenshots requested by the user.

Windows Game Bar recordings use the normal Windows Captures location. Support bundles are created only when requested and are privacy-redacted before export; OmniGPU does not upload them automatically.

## Network use

Network access occurs only when a feature the user invokes needs Windows Update or an approved vendor/service destination. OmniGPU has no application updater or background downloader.
