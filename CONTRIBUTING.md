# Contributing to the public OmniGPU repository

This repository is a documentation, compatibility and support hub. OmniGPU application/source development remains private.

Welcome here:

- factual documentation corrections;
- reproducible compatibility reports with personal data removed;
- accessibility and translation corrections;
- links to official vendor/Windows API documentation relevant to a feature request;
- responsible security reports through the private route in `SECURITY.md`.

Not accepted here:

- application/source-code submissions or reverse-engineered control tables;
- application package files, mirrors, repacks, private links or redistributed vendor SDKs;
- unverified overclock values or instructions to bypass safety/signature controls;
- receipts, credentials, personal logs or customer information.

Before proposing a documentation change, open an issue describing the exact page, current wording, proposed wording and source. Public contributions may be edited for consistency with the OmniGPU brand and compatibility policy.
